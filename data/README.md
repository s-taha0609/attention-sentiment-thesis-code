# Data directory

No empirical data are distributed with this package.

Place lawfully obtained, schema-conformant inputs in a local ignored subdirectory
such as `data/input/`. Do not commit article text, expression vocabularies
derived from real corpora, estimated real-data lexicons, firm-day sentiment,
private panels, or third-party datasets unless you have independently verified
that redistribution is permitted.

The synthetic files used by tests live under `tests/fixtures/` and are not
empirical observations.
